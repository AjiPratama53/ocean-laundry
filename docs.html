OceanLaundry API (0.1.0)

Download OpenAPI specification:

License: LicenseRef-Proprietary

Layanan laundry antar-jemput yang menghubungkan customer, kurir, dan staff outlet dalam satu alur: pemilihan paket, penjemputan, penimbangan & penetapan harga, pembayaran, pencucian, dan pengantaran Kembali.

All monetary amounts are integers in the minor unit of Indonesian Rupiah (IDR). Clients MUST ignore unknown response fields.

Authorizations:
bearerAuth
header Parameters
Idempotency-Key
required
string <uuid>

UUID version 4 in canonical hyphenated form. Required on POST /v1/orders and POST /v1/payments. Keys are retained for 24 hours. If the same key is reused with an identical body, the server returns the previously stored response without processing the request again. If the same key is reused with a different body, the server returns 409 Conflict with type https://oceanlaundry.api/problems/idempotency-key-reuse.

Make a payment

Records a payment for an order. Transitions the order from awaiting_payment to paid. Returns 409 if the order is not in awaiting_payment status.

Authorizations:
bearerAuth
header Parameters
Idempotency-Key
required
string <uuid>

UUID version 4 in canonical hyphenated form. Required on POST /v1/orders and POST /v1/payments. Keys are retained for 24 hours. If the same key is reused with an identical body, the server returns the previously stored response without processing the request again. If the same key is reused with a different body, the server returns 409 Conflict with type https://oceanlaundry.api/problems/idempotency-key-reuse.

Request Body schema: application/json
required
orderId
required
string
amount
required
integer >= 1

Amount in minor unit of IDR.
